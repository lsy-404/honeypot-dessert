# 蜜罐甜品屋

经营一家甜品屋：安排客人落座、点单、制作饮品和甜品、上菜结账，用赚来的金币升级店铺、解锁食谱和装修，后期可雇用自动接待的「聪明的服务员」和自己找座的「聪明的顾客」。纯前端单页游戏，存档保存在当前浏览器（8 个存档位，另有每天打烊时的自动存档）。

- 作者：槃清
- 当前版本：智能经营版
- 在线游玩：[tiny.leisiyu.dev/games/honeypot-dessert/](https://tiny.leisiyu.dev/games/honeypot-dessert/)

## 本地运行

无需构建，直接用浏览器打开 `index.html`，或在仓库目录启动任意静态服务器，例如：

```bash
python3 -m http.server 8000
```
